# Gen AI Interview

AI-powered interview preparation platform. Upload a resume and a job description, and get back a personalized interview report — match score, technical and behavioral questions with coaching-style answers, identified skill gaps, and a day-by-day prep roadmap — plus a tailored, ATS-friendly resume PDF, all generated by Google Gemini.

## Features

- **Account auth** — register/login with hashed passwords and a JWT session stored in an httpOnly cookie
- **Resume input** — upload a PDF resume or type a free-text self-description
- **AI interview report** — match score against the job description, technical questions, behavioral questions, skill gaps by severity, and a day-by-day preparation roadmap
- **AI resume generation** — a resume tailored to the target job description, rendered to a downloadable PDF
- **Report history** — revisit any previously generated report

## Tech stack

| Layer | Technology |
|---|---|
| Frontend | React 19, Vite, React Router 7, Sass, axios |
| Backend | Node.js, Express, MongoDB (Mongoose), JWT auth |
| AI | Google Gemini (`@google/genai`), structured JSON output via Zod |
| File handling | Multer (upload), `pdf-parse` (resume text extraction), Puppeteer (HTML → PDF) |

## Prerequisites

- Node.js 18 or later
- A MongoDB connection string (local instance or [MongoDB Atlas](https://www.mongodb.com/atlas))
- A [Google Gemini API key](https://ai.google.dev/)

## Getting started

### 1. Clone the repo

```bash
git clone https://github.com/JeetKumbhar/Gen-AI-Interview.git
cd Gen-AI-Interview
```

### 2. Backend setup

```bash
cd Backend
npm install
```

Create a `.env` file in `Backend/` with:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_signing_secret
GOOGLE_GENAI_API_KEY=your_gemini_api_key
```

Start the backend in dev mode (auto-restarts on file changes):

```bash
npm run dev
```

The API runs on `http://localhost:3000`.

### 3. Frontend setup

In a separate terminal:

```bash
cd Frontend
npm install
npm run dev
```

The app runs on `http://localhost:5173`.

### 4. Open the app

Visit `http://localhost:5173`, register an account, and generate your first report.

## API overview

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| POST | `/api/auth/register` | Public | Create an account |
| POST | `/api/auth/login` | Public | Log in |
| GET | `/api/auth/logout` | Public | Log out |
| GET | `/api/auth/get-me` | Private | Get the current user |
| POST | `/api/interview/` | Private | Generate a new interview report |
| GET | `/api/interview/report/:interviewId` | Private | Get a report by ID |
| GET | `/api/interview/` | Private | List the current user's reports |
| POST | `/api/interview/resume/pdf/:interviewReportId` | Private | Generate and download a tailored resume PDF |
